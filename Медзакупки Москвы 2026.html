РАЗДЕЛ 8

Методика и источники

Как собраны данные

  1. Закупки 2026 года взяты из открытых зеркал ЕИС: BidsFactory (данные проекта «ГосПлан»), Saby Тендеры, Ростендер и Бикотендер. Портал zakupki.gov.ru недоступен из-за рубежа, поэтому полной выгрузки нет.
  2. Выборка — процедур заказчиков системы ДЗМ с апреля по октябрь 2026 года. Это крупнейшие найденные процедуры каждого заказчика, а не случайная выборка.
  3. «НМЦК» — начальная цена из извещения. «Итог» — сумма, которую зеркало показывает для завершённой закупки; часто она совпадает с НМЦК, то есть снижения цены может не отражать.
  4. Накопленный объём заказчика — сумма всех его контрактов в ЕИС по данным synapsenet.ru за все годы.
  5. Сигналы риска считаются автоматически по правилам, описанным в разделе 4. Они указывают, куда смотреть, и не являются выводом о нарушении.

Для полной выгрузки из России: ЕИС → расширенный поиск → регион «Москва», заказчики ДЗМ, ОКПД2 21 (лекарства) и 32.50 (медизделия) → экспорт результатов в Excel.

Ограничения

  • Суммы по выборке нельзя трактовать как общий объём закупок ДЗМ в 2026 году.
  • Распределение по месяцам смещено источниками: BidsFactory охватывает в основном апрель–июль, Ростендер — первую половину октября.
  • Для заказчиков без найденного накопленного объёма рейтинг построен по активности 2026 года.
  • Цифра по вакцинам (28,54 млрд ₽) считается по региону заказчика и включает федеральную программу.
  • ИНН победителей-предпринимателей показаны как в источнике, без расшифровки.
